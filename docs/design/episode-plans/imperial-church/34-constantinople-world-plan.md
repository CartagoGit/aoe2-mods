## Problema y ritmo elegidos

Tras la derrota de Adrianópolis y la preparación de Sirmio, este episodio sirve de recuperación con decisiones de asignación. Dos trabajadores originales atienden una comida y alojamiento para dos hogares originales. Cada servicio permite tres métodos que compiten por un presupuesto finito; los lugares de trabajo y recepción son distintos. El trabajo produce únicamente la salida del método elegido. Pagar o visitar otro patio no equivale a servir.

La dificultad limita las parejas asequibles y el margen para ayuda opcional. Los recorridos hacen visible el coste espacial: la compra del mercader conserva alimento y madera pero exige un circuito occidental largo; el fogón consume más madera y usa un circuito interior corto. La reparación opcional puede requerir auxilio previo. Esto sigue siendo una hipótesis de interés: no se declara reto táctico medido, plazo oculto ni batalla para dar actividad. El revisor puede exigir un rediseño si la experiencia real sólo resulta caminar tras un menú.
