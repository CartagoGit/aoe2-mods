# Imágenes y mapas

Manifiesto por recurso: ID, descripción, ruta, origen, autor/proveedor, URL, licencia, restricciones, fecha, campañas, prompt/modelo si generado, revisión, formato, resolución, SHA-256 y coste. La licencia de una web no sustituye la del archivo concreto. No reutilizar imágenes comerciales de videojuegos/películas sin permiso.

Fuentes de búsqueda previstas: Wikimedia Commons por archivo, Met Open Access con CC0 identificado, Smithsonian Open Access con permiso específico. El investigador conserva página del objeto, autor, referencia museística y estado de derechos. No descargar por parecer antiguo.

Dirección artística: paleta sobria de pergamino, tinta y pigmentos; composición legible con zonas para texto; personajes coherentes entre imágenes; vestimenta y objetos respaldados por referencias; diferencias culturales sin caricatura. Los retratos reconstruidos se etiquetan como interpretación artística.

Mapas reconstruidos usan coordenadas/cartografía documentada, fecha y fronteras de incertidumbre. Un generador visual no es fuente histórica de geografía. Las escenas creadas con ChatGPT u otro proveedor guardan prompt, versión y limitaciones. El contrato no fija dimensiones nativas inventadas: PNG se valida frente al manifiesto y la resolución de la plantilla acreditada.
