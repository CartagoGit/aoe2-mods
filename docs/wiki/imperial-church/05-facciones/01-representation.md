# Facciones y civilizaciones

Para cada escenario documentar institución/grupo, momento y región, liderazgo, objetivos, composición/economía y civilización de AoE2 elegida. Seleccionar desde config/engine-catalog.json y comprobar disponibilidad/DLC. Explicar la representación y anacronismos en el dossier y en notas para el jugador cuando afecten a interpretación.

El fixture usa Byzantines solo para probar exportación y no aprueba esa elección paraRoma312. La propuesta de contenido debe evaluar Romanos y otras variantes acreditadas; no mezclar datasets de Return of Rome con estándar. Las comunidades del concilio no se equiparan a ejércitos por confesión ni se convierten en blancos religiosos.

Un refuerzo tiene origen/cantidad/causa y contrajuego. Un enemigo mantiene producción real mediante PER o reserva explícita; no crear unidades ilimitadas para simular una institución.
